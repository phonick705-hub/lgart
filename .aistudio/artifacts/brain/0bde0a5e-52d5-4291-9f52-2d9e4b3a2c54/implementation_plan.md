# 예매 좌석 번호 정리기 구현 계획서

예매 시스템에서 복사한 좌석 내역(예: `VIP석 1열 1번`)을 등급 및 열별로 그룹화하고, 연속된 좌석 번호를 물결표(`~`) 범위로 간결하게 정리하여 복사할 수 있는 단일 목적 웹 애플리케이션입니다.

### User Review & Critical Decisions

> [!IMPORTANT]
> - **줄바꿈 및 정렬 기준**: 질문 단계에서 추천된 표준 방식대로 등급·열별 줄바꿈 표기(`VIP석 1열: 1~3번, 5번\nVIP석 2열: 1번`) 및 등급/열/좌석 번호 오름차순 자연 정렬을 기본 적용합니다.
> - **불필요한 기능 배제 원칙**: 사용자 요구사항("요청한 것 외의 기능과 화면은 만들지 마세요")에 따라 부가적인 화면 전환, 챗봇, 불필요한 설정 창을 배제하고 단일 직관 뷰로 구축합니다.

- **기본 선택 1**: 등급 및 열별 개별 줄바꿈 출력 (`[등급] [열]: [좌석목록]`)
- **기본 선택 2**: 좌석 번호 자연 오름차순 정렬 및 2개 이상 연속 번호 물결표(`~`) 축약
- **기본 선택 3**: 초기 실행 방지(버튼 클릭 시에만 파싱/정리 실행), 초기 5줄 가상 예시 데이터 사전 입력

---

### 1. Overview & Core Concept

- **목적**: 티켓팅 후 지인에게 공유하거나 커뮤니티, 티켓 양도/확인 시 길고 분산된 좌석 목록을 규격화된 한눈에 보기 쉬운 텍스트로 요약.
- **주요 가치**:
  - 수작업으로 좌석 번호를 묶는 번거로움 해소
  - 오타 및 누락 방지
  - 결과물 원클릭 클립보드 복사

---

### 2. User Experience & Visual Design

- **레이아웃 구조**:
  - 깔끔하고 집중도 높은 단일 페이지 레이아웃 (최대 너비 720px의 정돈된 중앙 캔버스).
  - 상단: 서비스 명칭(`예매 좌석 번호 정리기`)과 간결한 안내 한 줄.
  - 본문 상단: 좌석 내역 텍스트 입력 영역 (가상 예시 데이터 5줄 기본 배치).
  - 중앙: 정리 실행 버튼(`좌석 번호 정리하기`).
  - 본문 하단: 유효성 검사 오류 안내 상자 또는 정리 결과 영역(결과 텍스트 박스 + 클립보드 복사 버튼).
- **시각 디자인 & 테마**:
  - 팔레트: 차분한 Slate/Zinc 계열의 배경과 카드, 시인성 높은 인디고/블루 악센트 버튼.
  - 타이포그래피: 깔끔한 산세리프 및 좌석 번호용 `tabular-nums` 고정폭 숫자.
  - 버튼 및 복사 상태: 클릭 시 햅틱 피드백 느낌의 전환과 "복사되었습니다" 알림 상태 전환.
- **에러/예외 상태 시각화**:
  - 빈 입력, 누락된 항목, 파싱 불가능한 잘못된 형식이 포함된 경우 눈에 잘 띄는 경고 텍스트와 함께 이전 결과 초기화.

---

### 3. Key Product Decisions & Trade-Offs

- **파싱 및 유효성 검증 정규식 엔진**:
  - 다양한 예매처의 텍스트 패턴(공백 유무, 등급명 다양성, '열', '번' 접미사)을 유연하게 수용하면서도 필수 구성요소(등급, 열, 번호) 누락 시 엄격히 실패 처리.
  - 패턴: `^([가-힣a-zA-Z0-9\s]+?)\s*([0-9A-Za-z]+)\s*열\s*([0-9]+)\s*번?$` 또는 탭/공백 구분형.
- **연속 번호 축약 알고리즘**:
  - 정렬된 좌석 번호 배열 `[1, 2, 3, 5]`를 순회하며 `[1..3]`, `[5]` 구간 분할.
  - 2개 이상 연속인 경우 `시작~끝번` (예: `1~2번`, `1~3번`), 단일 번호인 경우 `단일번` (예: `4번`, `5번`).
  - 쉼표로 연결: `1~3번, 5번`.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   App (Main View)                      │
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 1. 입력 칸 (Textarea)                            │  │
│  │    - 5줄 가상 예시 데이터 기본 탑재               │  │
│  └──────────────────────────────────────────────────┘  │
│                           │                            │
│                           ▼                            │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 2. 실행 버튼 ("좌석 번호 정리하기")              │  │
│  └──────────────────────────────────────────────────┘  │
│                           │ (OnClick Trigger)          │
│                           ▼                            │
│           ┌───────────────────────────────┐            │
│           │ Parsing & Validation Pipeline │            │
│           └───────────────────────────────┘            │
│              │ (검증 실패)         │ (검증 통과)        │
│              ▼                     ▼                   │
│  ┌───────────────────────┐  ┌───────────────────────┐  │
│  │ 에러 안내 문구 표시   │  │ 결과 텍스트 박스       │  │
│  │ (결과 미생성)         │  │ + 원클릭 복사 버튼    │  │
│  └───────────────────────┘  └───────────────────────┘  │
└────────────────────────────────────────────────────────┘
```

- **상태 관리**:
  - `inputText`: 사용자가 입력한 좌석 텍스트 (초기값: 5줄 예시)
  - `resultText`: 정리 완료된 결과 문자열 (초기값: 빈 문자열, 초기 실행 없음)
  - `errorMessage`: 유효성 검사 실패 시 안내 문구
  - `copied`: 복사 버튼 피드백 상태 (토스트/버튼 라벨 변경)
- **정상 작동 검증 케이스**:
  - 입력: `R석 1열 1번\nR석 1열 2번\nR석 1열 4번`
  - 결과: `R석 1열: 1~2번, 4번`
